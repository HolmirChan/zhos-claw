# RK3506 使用笔记

## 目录结构

| 路径 | 用途 |
|------|------|
| `/data/zhosclaw/` | 二进制文件（gateway、web 服务、CA 证书） |
| `/opt/zhosclaw/.zhosclaw/` | 运行时数据（config、workspace、密钥、日志） |
| `/etc/init.d/S81zhosclaw` | 开机自启脚本 |

---

## 一、手动部署

### 前置条件

- 开发机已安装 `hdc`（OpenHarmony Device Connector）
- 准备好以下文件：
  - `scripts/deploy-rk3506/cert.pem`（CA 证书包，从开发机 `/etc/ssl/cert.pem` 复制）
  - `scripts/deploy-rk3506/zhosclaw_ed25519.key`（私钥）
  - `scripts/deploy-rk3506/passphrase.txt`（加密口令）

### 步骤

**1. 编译**

```bash
make build-rk3506
```

产物：`build/zhosclaw-linux-arm`、`build/zhosclaw-web-linux-arm`

**2. 连接设备**

```bash
hdc conn <DEVICE_IP>:5555
```

**3. 停止旧进程、创建目录**

```bash
hdc -t <DEVICE_IP>:5555 shell "pkill -f zhosclaw-web || true; pkill -f zhosclaw || true"
hdc -t <DEVICE_IP>:5555 shell "mkdir -p /data/zhosclaw /opt/zhosclaw/.zhosclaw /opt/zhosclaw/.zhosclaw/logs"
```

**4. 上传文件**

```bash
hdc -t <DEVICE_IP>:5555 file send scripts/deploy-rk3506/cert.pem              /data/zhosclaw/cert.pem
hdc -t <DEVICE_IP>:5555 file send scripts/deploy-rk3506/zhosclaw_ed25519.key  /opt/zhosclaw/.zhosclaw/zhosclaw_ed25519.key
hdc -t <DEVICE_IP>:5555 file send build/zhosclaw-linux-arm                    /data/zhosclaw/zhosclaw-linux-arm
hdc -t <DEVICE_IP>:5555 file send build/zhosclaw-web-linux-arm                /data/zhosclaw/zhosclaw-web-linux-arm
```

**5. 设置权限和软链接**

```bash
hdc -t <DEVICE_IP>:5555 shell "chmod +x /data/zhosclaw/zhosclaw-linux-arm /data/zhosclaw/zhosclaw-web-linux-arm"
hdc -t <DEVICE_IP>:5555 shell "chmod 600 /opt/zhosclaw/.zhosclaw/zhosclaw_ed25519.key"
hdc -t <DEVICE_IP>:5555 shell "ln -sf /data/zhosclaw/zhosclaw-linux-arm /data/zhosclaw/zhosclaw"
```

> 软链接是必要的：web 服务通过固定名字 `zhosclaw` 查找并拉起 gateway，找不到则无法启动 gateway。

**6. 首次部署：初始化 home 目录**

> 重复部署跳过此步，已有配置不会被覆盖。

```bash
# 生成干净的 config.json（去除示例注释和废弃字段）
jq --arg ws "/opt/zhosclaw/.zhosclaw/workspace" '
    .agents.defaults.workspace = $ws |
    walk(if type == "object" then with_entries(select(.key != "_comment")) else . end) |
    del(.tools.web.brave.api_key, .tools.web.perplexity.api_key, .tools.web.tavily.api_key)
' config/config.example.json > /tmp/zhosclaw_deploy_config.json

hdc -t <DEVICE_IP>:5555 file send /tmp/zhosclaw_deploy_config.json /opt/zhosclaw/.zhosclaw/config.json
hdc -t <DEVICE_IP>:5555 file send cmd/picoclaw/internal/onboard/workspace /opt/zhosclaw/.zhosclaw/workspace
```

**7. 生成开机自启脚本并启动**

```bash
cat > /tmp/S81zhosclaw << 'EOF'
#!/bin/sh
export PICOCLAW_HOME=/opt/zhosclaw/.zhosclaw
export PICOCLAW_SSH_KEY_PATH=/opt/zhosclaw/.zhosclaw/zhosclaw_ed25519.key
export PICOCLAW_KEY_PASSPHRASE=<口令>
export SSL_CERT_FILE=/data/zhosclaw/cert.pem
GODEBUG=asyncpreemptoff=1 nohup /data/zhosclaw/zhosclaw-web-linux-arm -public >> /opt/zhosclaw/.zhosclaw/logs/launcher.log 2>&1 &
EOF

hdc -t <DEVICE_IP>:5555 file send /tmp/S81zhosclaw /etc/init.d/S81zhosclaw
hdc -t <DEVICE_IP>:5555 shell "chmod +x /etc/init.d/S81zhosclaw && sync"
hdc -t <DEVICE_IP>:5555 shell "/etc/init.d/S81zhosclaw"
```

访问 `http://<DEVICE_IP>:18800`，在 Web UI 中配置 API Key 后点击「启动服务」。

## 二、一键部署

### 前置条件

准备 `scripts/deploy-rk3506/` 目录下的三个文件（均已加入 `.gitignore`）：

```
scripts/deploy-rk3506/
├── cert.pem                 # 从开发机 /etc/ssl/cert.pem 复制
├── zhosclaw_ed25519.key     # 私钥
└── passphrase.txt           # 加密口令（一行纯文本）
```

### 运行

```bash
DEVICE_IP=192.168.x.x bash scripts/deploy-rk3506.sh
```

端口默认 `5555`，如需覆盖：

```bash
DEVICE_IP=192.168.x.x DEVICE_PORT=5555 bash scripts/deploy-rk3506.sh
```

脚本会自动完成编译、上传、权限配置、首次初始化、开机自启注册和服务启动。

## 三、常用命令

**查看服务是否在运行**

```bash
grep -l zhosclaw /proc/*/cmdline 2>/dev/null
```

有输出（如 `/proc/713/cmdline`）说明进程存活，`ps` 在该设备上不可靠。

**停止服务**

```bash
pkill -f zhosclaw-web || true
pkill -f zhosclaw || true
```

**查看端口占用**

```bash
netstat -tlnp | grep 18800
```

**查看日志**

```bash
cat /opt/zhosclaw/.zhosclaw/logs/launcher.log
cat /opt/zhosclaw/.zhosclaw/logs/launcher_panic.log
```

**手动启动服务**

```bash
/etc/init.d/S81zhosclaw
```

**还原干净设备**

```bash
pkill -f zhosclaw-web || true
pkill -f zhosclaw || true
rm -rf /data/zhosclaw
rm -rf /opt/zhosclaw
# 用 vi 手动清理 /etc/profile 中追加的环境变量（如有）
# 用 vi 清空或删除 /etc/init.d/S81zhosclaw
```

## 四、常见问题

### `j_async: bad nzombie` 导致进程崩溃

**原因**：RK3506 内核版本较旧，不支持 Go runtime 的异步抢占。

**解决**：启动时加 `GODEBUG=asyncpreemptoff=1`，已内置在 `S81zhosclaw` 中。

---

### TLS 证书验证失败 `x509: certificate signed by unknown authority`

**原因**：设备没有 CA 根证书，无法验证 HTTPS 请求。

**解决**：
1. 从开发机复制证书包：`cp /etc/ssl/cert.pem scripts/deploy-rk3506/cert.pem`
2. 部署脚本会上传到 `/data/zhosclaw/cert.pem` 并通过 `SSL_CERT_FILE` 指定路径

---

### 端口 18800 已被占用

**原因**：上次部署的进程未被杀干净，或重复执行了启动命令。

**解决**：
```bash
pkill -f zhosclaw-web || true
# 确认清理干净
grep -l zhosclaw /proc/*/cmdline 2>/dev/null
```

---

### `config.json contains unknown field(s)`

**原因**：`config.example.json` 中包含 `_comment` 伪注释字段和废弃的 `api_key` 单数字段，直接复制会被解析器拒绝。

**解决**：部署脚本已通过 `jq` 自动清理，手动修复方法：

```bash
jq --arg ws "/opt/zhosclaw/.zhosclaw/workspace" '
    .agents.defaults.workspace = $ws |
    walk(if type == "object" then with_entries(select(.key != "_comment")) else . end) |
    del(.tools.web.brave.api_key, .tools.web.perplexity.api_key, .tools.web.tavily.api_key)
' config/config.example.json > /tmp/zhosclaw_deploy_config.json

hdc -t <DEVICE_IP>:5555 file send /tmp/zhosclaw_deploy_config.json /opt/zhosclaw/.zhosclaw/config.json
```

---

### systray DBus 错误（`launcher_panic.log`）

**原因**：设备无桌面环境，systray 初始化失败触发 panic，被 recover 捕获写入 `launcher_panic.log`。

**影响**：不影响 web 服务正常运行，可忽略。
