# RK3506 使用笔记

## 目录结构

| 路径 | 用途 |
|------|------|
| `/userdata/zaiagent/` | 所有文件（二进制、配置、密钥、证书、工作区、日志） |
| `/userdata/zaiagent/.zaiagent/` | 运行时数据（config、workspace、密钥、日志） |
| `/etc/init.d/S81zaiagent` | 开机自启脚本 |

---

## 一、手动部署

### 前置条件

- 开发机已安装 `hdc`（OpenHarmony Device Connector）
- 准备好以下文件：
  - `scripts/deploy-rk3506/cert.pem`（CA 证书包，从开发机 `/etc/ssl/cert.pem` 复制）
  - `scripts/deploy-rk3506/zaiagent_ed25519.key`（私钥）
  - `scripts/deploy-rk3506/passphrase.txt`（加密口令）

### 步骤

**1. 编译**

```bash
make build-rk3506
```

产物：`build/zaiagent-linux-arm`、`build/zaiagent-web-linux-arm`

**2. 连接设备**

```bash
hdc tconn <DEVICE_IP>:5555
```

**3. 停止旧进程、创建目录**

```bash
hdc -t <DEVICE_IP>:5555 shell "pkill -f zaiagent-web || true"
hdc -t <DEVICE_IP>:5555 shell "pkill -f zaiagent || true"
hdc -t <DEVICE_IP>:5555 shell "mkdir -p /userdata/zaiagent /userdata/zaiagent/.zaiagent"
```

**4. 上传文件**

```bash
hdc -t <DEVICE_IP>:5555 file send scripts/deploy-rk3506/cert.pem              /userdata/zaiagent/cert.pem
hdc -t <DEVICE_IP>:5555 file send scripts/deploy-rk3506/zaiagent_ed25519.key  /userdata/zaiagent/.zaiagent/zaiagent_ed25519.key
hdc -t <DEVICE_IP>:5555 file send build/zaiagent-linux-arm                    /userdata/zaiagent/zaiagent-linux-arm
hdc -t <DEVICE_IP>:5555 file send build/zaiagent-web-linux-arm                /userdata/zaiagent/zaiagent-web-linux-arm
```

**5. 设置权限**

```bash
hdc -t <DEVICE_IP>:5555 shell "chmod +x /userdata/zaiagent/zaiagent-linux-arm /userdata/zaiagent/zaiagent-web-linux-arm"
hdc -t <DEVICE_IP>:5555 shell "chmod 600 /userdata/zaiagent/.zaiagent/zaiagent_ed25519.key"
```

**6. 首次部署：初始化 home 目录**

> 重复部署跳过此步，已有配置不会被覆盖。

```bash
# 生成干净的 config.json（去除示例注释和废弃字段）
jq --arg ws "/userdata/zaiagent/.zaiagent/workspace" '
    .agents.defaults.workspace = $ws |
    walk(if type == "object" then with_entries(select(.key != "_comment")) else . end) |
    del(.tools.web.brave.api_key, .tools.web.perplexity.api_key, .tools.web.tavily.api_key)
' config/config.example.json > /tmp/zaiagent_deploy_config.json

hdc -t <DEVICE_IP>:5555 file send /tmp/zaiagent_deploy_config.json /userdata/zaiagent/.zaiagent/config.json
hdc -t <DEVICE_IP>:5555 file send cmd/picoclaw/internal/onboard/workspace /userdata/zaiagent/.zaiagent/workspace
```

**7. 生成开机自启脚本并启动**

```bash
cat > /tmp/S81zaiagent << 'EOF'
#!/bin/sh
export ZAIAGENT_HOME=/userdata/zaiagent/.zaiagent
export ZAIAGENT_SSH_KEY_PATH=/userdata/zaiagent/.zaiagent/zaiagent_ed25519.key
export ZAIAGENT_KEY_PASSPHRASE=<口令>
export ZAIAGENT_BINARY=/userdata/zaiagent/zaiagent-linux-arm
export SSL_CERT_FILE=/userdata/zaiagent/cert.pem
mkdir -p /userdata/zaiagent/.zaiagent/logs
GODEBUG=asyncpreemptoff=1 nohup /userdata/zaiagent/zaiagent-web-linux-arm -public >> /userdata/zaiagent/.zaiagent/logs/launcher.log 2>&1 &
EOF

hdc -t <DEVICE_IP>:5555 file send /tmp/S81zaiagent /etc/init.d/S81zaiagent
hdc -t <DEVICE_IP>:5555 shell "chmod +x /etc/init.d/S81zaiagent && sync"
hdc -t <DEVICE_IP>:5555 shell "/etc/init.d/S81zaiagent"
```

> `ZAIAGENT_BINARY` 显式指定 gateway 二进制路径，web launcher 启动时会据此自动拉起 gateway。

访问 `http://<DEVICE_IP>:18800`，在 Web UI 中配置 API Key 后点击「启动服务」。

## 二、一键部署

### 前置条件

准备 `scripts/deploy-rk3506/` 目录下的三个文件（均已加入 `.gitignore`）：

```
scripts/deploy-rk3506/
├── cert.pem                 # 从开发机 /etc/ssl/cert.pem 复制
├── zaiagent_ed25519.key     # 私钥
└── passphrase.txt           # 加密口令（一行纯文本）
```

### 运行

```bash
DEVICE_IP=192.168.x.x bash scripts/deploy-rk3506.sh
```

端口默认 `5555`，如需覆盖：

```bash
DEVICE_IP=192.168.x.x DEVICE_PORT=5555 bash scripts/deploy-rk3506.sh
```

脚本会自动完成编译、上传、权限配置、首次初始化、开机自启注册和服务启动。

## 三、常用命令

**查看服务是否在运行**

```bash
grep -l zaiagent /proc/*/cmdline 2>/dev/null
```

有输出（如 `/proc/713/cmdline`）说明进程存活，`ps` 在该设备上不可靠。

**停止服务**

```bash
# 必须分两次执行：同一条 hdc shell 内分号后的命令会在首个 kill 断开后丢失
pkill -f zaiagent-web || true
pkill -f zaiagent || true
```

**查看端口占用**

```bash
netstat -tlnp | grep 18800
```

**查看日志**

```bash
cat /userdata/zaiagent/.zaiagent/logs/launcher.log
cat /userdata/zaiagent/.zaiagent/logs/launcher_panic.log
```

**手动启动服务**

```bash
/etc/init.d/S81zaiagent
```

**还原干净设备**

```bash
# 必须分两次执行：同一条 hdc shell 内分号后的命令会在首个 kill 断开后丢失
pkill -f zaiagent-web || true
pkill -f zaiagent || true
rm -rf /userdata/zaiagent
rm -f /etc/init.d/S81zaiagent
```

## 四、常见问题

### `j_async: bad nzombie` 导致进程崩溃

**原因**：RK3506 内核版本较旧，不支持 Go runtime 的异步抢占。

**解决**：启动时加 `GODEBUG=asyncpreemptoff=1`，已内置在 `S81zaiagent` 中。

---

### TLS 证书验证失败 `x509: certificate signed by unknown authority`

**原因**：设备没有 CA 根证书，无法验证 HTTPS 请求。

**解决**：
1. 从开发机复制证书包：`cp /etc/ssl/cert.pem scripts/deploy-rk3506/cert.pem`
2. 部署脚本会上传到 `/userdata/zaiagent/cert.pem` 并通过 `SSL_CERT_FILE` 指定路径

---

### 端口 18800 已被占用

**原因**：上次部署的进程未被杀干净，或重复执行了启动命令。

**解决**：
```bash
pkill -f zaiagent-web || true
# 确认清理干净
grep -l zaiagent /proc/*/cmdline 2>/dev/null
```

---

### `config.json contains unknown field(s)`

**原因**：`config.example.json` 中包含 `_comment` 伪注释字段和废弃的 `api_key` 单数字段，直接复制会被解析器拒绝。

**解决**：部署脚本已通过 `jq` 自动清理，手动修复方法：

```bash
jq --arg ws "/userdata/zaiagent/.zaiagent/workspace" '
    .agents.defaults.workspace = $ws |
    walk(if type == "object" then with_entries(select(.key != "_comment")) else . end) |
    del(.tools.web.brave.api_key, .tools.web.perplexity.api_key, .tools.web.tavily.api_key)
' config/config.example.json > /tmp/zaiagent_deploy_config.json

hdc -t <DEVICE_IP>:5555 file send /tmp/zaiagent_deploy_config.json /userdata/zaiagent/.zaiagent/config.json
```

---

### systray DBus 错误（`launcher_panic.log`）

**原因**：设备无桌面环境，systray 初始化失败触发 panic，被 recover 捕获写入 `launcher_panic.log`。

**影响**：不影响 web 服务正常运行，可忽略。
